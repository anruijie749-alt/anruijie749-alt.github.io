核心能力

它每天替你盯住网站，把"漏检"和"忘存档"这两件事交给机器。

🔍

全站巡检

47 个条目（含子目录）逐文件检查编码、资源引用、死链与占位内容。

🗂️

A/B/C 分级

A 可安全修、B 需确认、C 禁止触碰；分级列清单，绝不自行越级处理。

📤

飞书推送

巡检摘要按固定结构（结论→行动项→待确认）推送到指定飞书群。

⏰

定时任务

每天 18:10 自动运行一次，也可飞书发"巡检 <范围>"即时触发。

📁

报告存档

每次运行生成带日期的 Markdown 报告 + 运行日志（时间、结果、输出链接）。

一次巡检的工作流

从指令到报告，共 7 步，全程可追溯。

1

锁定范围

只查用户指定范围，范围外只记录+提醒；文件不存在立即停止，不猜测。

2

建立回退基线

改前先备份（带时间戳、不覆盖），备份失败禁止修改。

3

逐页功能检查

页面加载、死链、交互响应、接口状态、乱码。

4

诊断与分级

现象/根因/方案/理由；A/B/C 分级，禁止投票，根因不足标"建议再验证"。

5

请示

问题清单+分级+方案逐项呈报，逐项批准；沉默 ≠ 同意。

6

修复与即时验证

只改已批准项，一步一验；验证不过立即还原备份。

7

报告与交付

生成巡检报告（7 要素）+ 飞书摘要；可上传清单列明，但不执行上传。

能力边界

能做什么、不能做什么，白纸黑字写死在规范里（SOUL.md）。

✅ 它能做

  • 本地全站巡检（47 条目 + 子目录）
  • 编码 / 资源引用 / 死链 / 占位内容检查
  • A/B/C 分级问题清单
  • 巡检报告生成与存档（Markdown）
  • 飞书群推送摘要、定时任务
  • 运行日志记录（时间 / 结果 / 输出链接）

⛔ 它绝不碰

  • 不自动修改代码（A 级也需先批准）
  • 不做 B/C 级修复、不删任何文件
  • 不改模型 / 配置 / 部署 / 环境
  • 不上传、不推送、不发布
  • 不越出允许目录，不读取范围外内容
  • 本页为公开演示：不接 API、不可调用、无数据回传
